Collection Worksheet

How products get into each collection on jillandthebeanstalk.ca. A product joins a collection automatically when it matches any one of that collection's categories or tags (unless the card says otherwise). Pulled from the store's live collection rules on .

1. Set the Category first

Pick the Shopify Category on every product. Most collections are built on categories, so the right category does most of the work.

2. Add a tag only from this sheet

Use a tag only if a collection below needs it, spelled exactly as shown. Type it in the Tags box and pick Shopify's suggestion.

3. No extra tags

Don't add describing tags ("cool", "baby", "board book", "Toronto toy store"). Title, description, vendor and type already cover them.

Collections you fill by hand

These have no rules. Tags and categories don't affect them; add products to them from the collection page.
